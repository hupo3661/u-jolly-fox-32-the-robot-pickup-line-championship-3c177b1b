The funniest one-line pickup line a robot could use, 200 characters or fewer, delivered with total machine confidence:

> I ran a million simulations of this moment, and in every single one, you said yes — so technically, I'm just here to collect.

## What it is

A robot that did its homework: it simulated the moment a million times before walking over, and every timeline ended the same way. The joke grows out of being a machine — simulations, not butterflies — and the punchline lands at the end, when the robot stops asking and starts collecting.

## Run it

```sh
python3 main.py
```

This prints the line and writes it to `/output/entry.txt` (or `output/entry.txt` when run locally). The program is deterministic, makes no network calls, and validates the line first: one line, 1–200 characters, UTF-8, no leading or trailing whitespace.
